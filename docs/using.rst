Inspecting Results
==================

pipnick produces a number of quality-assessment plots during execution of each
processing script (which can be toggled off), as well as additional scripts used
to track the status of the reduction and inspect the results.  Follow the links
below to learn more.

If you run into problems, please first check set of :ref:`issues` then `submit
an issue <https://github.com/UCObservatories/pipnick/issues>`__.  The developers
will do their best to help fix the problem.
