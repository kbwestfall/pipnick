Getting started
===============

To start using pipnick with your data, follow the link below to get instructions
for installing the software, then follow the quick-start tutorial.  The tutorial
contains links that will guide you through the rest of the documentation.

We track changes to the code as it develops.  Have a look at what's new in the
code to see if these changes affect you.
